# Base44 JavaScript SDK

## Writing JSDoc

The SDK reference docs are generated from the JSDoc in the source. Before you add or change any JSDoc, read `.claude/skills/sdk-docs-writing/SKILL.md` and follow it. This applies to feature work too, whenever it adds or changes a public method, type, or module, not only to docs-only changes. Run through the checklist at the end of the skill before opening the PR.
